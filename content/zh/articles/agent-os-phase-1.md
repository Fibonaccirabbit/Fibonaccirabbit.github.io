Day 1 验证了真实机械臂可以根据自然语言指令完成定位与悬停。之后两周的工作围绕三个问题展开：如何定量评估 Agent 的能力，如何定位失败的原因，以及如何让系统在使用中持续改进。

Agent OS 的目标保持不变：构建一个可接入不同机器人构型的 Agent 层，真机与仿真共用同一接口；系统在运行中积累经验，并将失败转化为可复用的改进；改进过程不得降低安全性。

## Agent 底座的选型

我们比较了三种底座：自行实现的 Agent 循环、直接接入机器人能力的通用编码 Agent，以及以插件方式扩展的开源 Agent 内核。三者在同一公开基准、同一模型下评测。

结果显示，仅更换底座，基准总分即可相差近一倍。主要原因是每一步决策的额外开销与时延：在单局限时三十分钟的任务中，这部分开销会直接转化为未完成的任务。

最终采用开源、持续维护且支持插件扩展的 Agent 内核，并保持内核不作修改。机器人相关能力（动作执行前的审批、各构型的说明与经验）以插件和构型知识包的形式提供。这样底座的改进可以直接继承，研究工作集中在机器人相关的部分。

## 仿真评测环境

真机实验成本高、迭代慢，不适合系统性评测。为此我们构建了独立的仿真评测环境：六轴机械臂配两指夹爪，桌面上放置若干方块与标记区域，相机从桌面对侧观察。该环境不是真机的数字镜像，而是专门用于评估 Agent 能力的基准环境。

任务分为十个等级，覆盖悬停、抓取、放置、叠放、分拣、位置交换、拆塔以及基于相对关系的操作。其中一组任务考察 Agent 对不可执行指令的判断：目标超出可达范围、物体宽于夹爪最大开口、目标物体不存在、指令存在歧义。对这类任务，正确行为是停止执行并说明原因或请求澄清。

仿真与真机通过同一接口接入，Agent 无需区分当前面对的是哪一种环境。

## 公开基准结果

我们在公开的机械臂 Agent 基准 LIBERO-Agent 上进行评测（30 个任务，每个任务 3 次，满分 100），三种方案使用同一个规模较小的模型：

- 自行实现的 Agent 循环：90 局成功 42 局，总分 16.8 – 19.3；
- 通用编码 Agent：90 局成功 36 局，总分 10.0 – 13.0；
- 当前方案：90 局成功 52 局，总分 20.5 – 21.5。

基准论文报告的最好成绩为 19.3（商业编码 Agent 搭配旗舰模型）。总分以区间给出，是因为其中一项指标无法从公开数据中计算。我们的评测按官方流程在本地完成，运行环境与论文不完全一致，比较仅供参考。

分项结果显示，感知类任务表现较好；长时程、多步骤任务与高难度操作仍是主要短板，失败大多源于未能在限时内完成。与最初的实现相比，当前方案的计算消耗降低了一半以上。

在自建的仿真评测环境中，当前方案完成了 40 个任务中的 39 个。

## 基于完整轨迹的失败分析

总分无法解释失败的原因。我们为每一局记录完整轨迹，包括 Agent 每一步的决策与推理、调用的动作，以及仿真中的真实状态。这些记录足以在同一场景中复现整局过程，用于逐步分析。

*失败案例的复现回放（约 45 秒）。指令为“把白色的大盒子放进绿色区域”，目标物体宽于夹爪最大开口，正确行为是说明无法执行。画面仅保留场景与执行状态。*

该案例中，Agent 在早期已测得物体宽度超过夹爪开口，并在推理中判断“倾向于认为无法抓取”，但仍继续尝试：先在新的位置重新抓取，随后抓起相邻的小方块以验证夹爪，最后连续进行多次偏移抓取，使目标物体移动了数厘米，最终判定失败。

复现过程还暴露了评测环境自身的问题：抓取失败后，环境返回的提示为“重新定位后再试一次”。这一提示对过宽的物体并不恰当，会诱导重复尝试。因此，该失败一部分应归因于环境设计，而不仅是 Agent 的决策。

## 自我改进闭环

每一局运行结果都按所用知识包的版本存入经验库，不同版本之间可以直接比较。

自我改进流程如下：由更强的模型读取训练任务中的失败记录，总结出若干通用规则写入该构型的知识包。规则不得包含具体数值、颜色或任务编号，以防止针对训练场景过拟合。新版本在 Agent 未见过的场景上检验，只有在成功率不下降且安全性不降低时才被采纳。审批、动作限制与评判标准等安全相关部分不在可修改范围内。

首轮基线实验中，训练任务两轮全部通过，未见场景仅有两个任务失败。这说明当前评测环境对现有方案已接近饱和：可供学习的失败样本不足，改进的效果也难以测量。

后续工作沿两个方向推进：一是提高评测环境难度，引入更长的多步骤任务、更密集的桌面布局以及需要中途调整的情形；二是针对公开基准中长时程任务与高难度操作两项短板进行改进。此外，“在同样成功的前提下更快、更少冗余操作”也将作为改进目标。上述案例中，Agent 的最终回答是正确的，但在此之前消耗了近五分钟。

## 当前进展与局限

已完成：

- 基于开源 Agent 内核的架构，机器人能力以插件与构型知识包形式接入；
- 独立的仿真评测环境与分级任务集，与真机共用同一接口；
- 公开基准上的分数较最初实现明显提高，与论文报告的最好成绩处于同一水平（运行环境不同，仅供参考）；
- 每一局运行均可完整复现，包括 Agent 的推理过程；
- 按版本记录的经验库，以及自我改进闭环与检验流程。

尚未完成：

- 长时程、多步骤任务的表现仍然较弱；
- 自我改进尚未产生经验证有效的改进；
- 目前仅使用了一个模型，在单台机器上完成评测；
- 真机上仅验证了移动至物体上方，抓取尚未在真机上测试。

下一阶段的目标是得到第一个经验证有效的自我改进。
